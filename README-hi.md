निर्माण अंतिम-निपटान दस्तावेज़ चेकलिस्ट की वास्तव में जमा किए गए दस्तावेज़ों से तुलना: गुम दस्तावेज़, कम प्रतियाँ, अनुपस्थित हस्ताक्षर/मुहर, वैकल्पिक दस्तावेज़ अनुपस्थित, और पूर्णता दर, CSV निर्यात के साथ। सब कुछ लोकल चलता है।

## पूरा दस्तावेज़

पूरा दस्तावेज़ (इंस्टॉल, अनुमतियाँ, उदाहरण और समस्या-निवारण) [README.md](README.md) और [README-zh.md](README-zh.md) में है।

## इंस्टॉल

```sh
dsh plugin --profile <profile> add dsh-settlement-docs
```

## अनुमतियाँ

पढ़ना: उपयोगकर्ता द्वारा दिए गए चेकलिस्ट और जमा CSV। लिखना: केवल `$DSH_HOME/dsh-settlement-docs/exports/`। नेटवर्क: नहीं। बाहरी सिस्टम: कोई नहीं।
